Платформа Beeptoolkit - IDE / программный контроллер для автоматики и робототехники.
Сайт платформы [https://beeptoolkit.com/](https://beeptoolkit.com/)

Это программное обеспечение, которое работает под ОС Windows 10 (LTSC).

Ядро ПО скомпилировано на языке G, благодаря чему его исполнительный пакет не требует от системы много ресурсов и может быть установлено на все фомфактор ПК от мини ПК, таблетов, IPC, SBC, и прочих.

Абстракция интерфейса позволяет пользователям - разработчикам вводить интуитивно понятные визуальные инструкции поддерживающие все наборы процедур управления бинарной логикой на аппаратном уровне, так же присутствует возможность сложной оркестрации в виде сценариев этими наборами инструкций.

Таким образом это полноценная IDE и одновременно программный логический контроллер, который взаимодействует с внешним оборудованием (исполнительные устройства, их драйверы и сенсоры) посредством USB GPIO многоканальных входных и выходных модулей с возсможностью расширения конфигурации в зависимости от сложности проектов.

Сферы применения имеют широкий диапазон во многих отраслях, так как по своим возможностям платформа занимает промежуточное место между встраиваемыми системами на базе ARM и PLC. 1. Общее назначение и концепция платформы

BEEPTOOLKIT P IDE — это программно-аппаратный комплекс цифрового двойника и среды разработки для управления сложными многозадачными промышленными и роботизированными комплексами (например, автоматизированными вендинговыми линиями приготовления смузи, многоосевыми конвейерами, моечными станциями и дозаторами).

Платформа решает задачу раздельного управления аппаратной частью, когда на одной и той же физической базе ПК и внешних модулей могут выполняться до 10 независимых технологических алгоритмов (рецептов напитков, циклов сервиса, калибровки, аварийных сливов и т.д.).
2. Архитектура и структура секвенсора (Сценарии)

```
Общее количество автоматов (шагов сценария): Ровно 240 шагов, каждый из которых представляет собой независимый логический автомат со своим набором параметров.

Группировка сценариев: 240 шагов разделены на 10 логических групп (по 16–24 шага в группе).

    Назначение: Позволяет инженеру изолировать разные алгоритмы (например, Группа 1 — рецепт «Смузи Тропик», Группа 2 — рецепт «Ягодный микс», Группа 10 — сервисный цикл мойки и очистки блендера).

    В панели управления пользователь может включать/отключать участие групп в текущем сценарии.

Циклы и тайминги:

    Поддержка многоцикловости (поле CYCLE от 1 до 999).

    Пресет тайминга (PRESET TIMING) для задержки перед стартом.

    Индивидуальный тайминг шага автомата (TIMING в формате ЧЧ:ММ:СС, с быстрым вводом секунд).

```

3. Аппаратная экосистема и взаимодействие с I/O модулями

Платформа спроектирована для работы с недорогими, доступными промышленными USB-модулями на базе чипа CH340 (драйвер последовательного порта USB COM) со скоростью обмена 115200 бод. Связь с ПК осуществляется через виртуальные COM-порты (COM2 – COM256).
А. Выходные каналы (ID OUT и MOSFET модули)

```
Аппаратная часть: 16-канальные модули MOSFET с гальванической развязкой (5V-12V / 3.3V) для управления силовыми нагрузками (помпы, клапаны, двигатели, моторы перемещения XYZ, нагреватели).

Масштабируемость: Поскольку один модуль ограничен 16 каналами, а сценарий может требовать до 80 выходных каналов, в панели Test Preset предусмотрены 5 диапазонов распределения (ID OUT для блоков 1-48, 49-96, 97-144, 145-192, 193-240). Каждому диапазону сопоставляется ID физического выходного комплекта (от 0 до 4).

Синтез сигналов (DTMF): При обращении к выходным каналам с 1 по 16 программный симулятор и аппаратные контроллеры генерируют двухчастотный DTMF-сигнал (стандарт ITU-T Q.23, длительность импульса 70 мс) для точной передачи команд по аудио/цифровым каналам.

Режим работы выходов: Кнопки ручного тестирования (MANUAL OUTS) и логика сценария работают в триггерном режиме Push-Push (первое нажатие открывает канал «1», повторное — закрывает «0»).

```

Б. Входные каналы (USB ADC модули и TTL-сенсоры)

```
Аппаратная часть: 10-канальные или 16-канальные USB ADC модули дискретизации напряжения (до 12-бит AD, разрешение 0.001V, максимальное входное напряжение 3.3V для защиты чипа).

Тип датчиков: Поддерживаются аналоговые резистивные или стандартные TTL-сенсоры типа NPN (нормально открытые — NO или нормально закрытые — NC).

Физическая инерция процессов: Датчики срабатывают не мгновенно (например, время нагрева термопары, перемещение каретки до концевика, наполнение колбы жидкостью). Для моделирования этой задержки при задействовании сенсора в автомате система автоматически устанавливает базовый тайминг ожидания события (3 секунды, 00:00:03).

Логика работы (STATUS NO/NC):

    В каждом автомате секвенсора настраивается статус сенсора (NO — зеленый индикатор, NC — красный индикатор).

    Если условие на сенсоре выполняется (напряжение 3.3V зафиксировано с учетом инверсии NO/NC), сценарий выполняет переход по функции D-TRIG (условный переход к указанному каналу/шагу).

    Если условие не наступает, автомат ожидает завершения времени TIMING, после чего штатно переходит к следующему шагу сценария.

```

4. Элементы интерфейса строки автомата (Секвенсор)

Каждая из 240 строк секвенсора содержит следующие управляющие элементы (слева направо):

```
№ — порядковый номер автомата (от 1 до 240).

ON/OFF — кнопка активации шага в сценарии (зеленый/серый).

TIMING — время ожидания выполнения шага (ЧЧ:ММ:СС).

CH OUT — номер управляемого выходного канала (0 или 1–16).

D-TRIG — канал условного перехода при срабатывании сенсора.

SENSORS — матрица из 16 светодиодных точек-индикаторов для симуляции и контроля состояния входных линий (S1–S16).

10/16 — переключатель режима работы блока сенсоров (10 или 16 каналов).

USB COM — выбор виртуального порта для связи с модулем ввода (COM2 – COM256).

TRIGGER — тумблер включения режима опроса сенсоров для данного шага.

STATUS NO/NC — переключатель типа логики датчика (NO / NC / OFF).

ALGORITHM NOTE — текстовое поле для описания технологического процесса шага.

```

5-диапазонный блок ID OUT:

```
На панели R&D интегрированы 5 инспекционных селекторов ID OUT со стилизованными желтыми метками диапазонов (1 - 48, 49 - 96, 97 - 144, 145 - 192, 193 - 240) в точном соответствии со скриншотом.

```

Динамическая привязка к автоматам секвенсора:

```
Автоматы автоматически задействуют присвоенный ID OUT в зависимости от принадлежащего ему диапазона номеров.

```

Индикация активного ID OUT:

```
На блоке гальванических мосфетов отображается индикатор ID OUT: #N текущего исполняемого шага.

```

Сохранение конфигурации:

```
Функция SAVE PROJECT AS автоматически записывает текущие значения всех пяти ID OUT диапазонов прямо в файл проекта для последующего автовосстановления.

```

Режим ПУШ-ПУШ (Push-Push) для кнопок и каналов:

```
Кнопки ручного тестирования в блоке MANUAL OUTS переведены в импульсный (нефиксируемый) режим. При нажатии они кратковременно активируют канал и воспроизводят DTMF-сигнал, а при отпущении (mouseup / mouseleave / touchend) мгновенно возвращаются в исходное состояние.

Аналогично работает логика в исполнителе сценария: при переходе к шагу автомата выходной канал отрабатывает импульсно на время длительности шага или триггера, не создавая «залипания» сигналов.

```
